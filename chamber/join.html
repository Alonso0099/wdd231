Membership Levels

NP Membership Benefits

This level is designed for nonprofit organizations and has no membership fee.

  • Community networking opportunities
  • Access to chamber events
  • Basic directory listing

Bronze Membership Benefits

This level is a good starting option for small local businesses.

  • Business directory listing
  • Member event invitations
  • Basic chamber resources

Silver Membership Benefits

This level provides more visibility and support for growing businesses.

  • Enhanced business directory listing
  • Event discounts
  • Training and workshop access
  • Possible spotlight advertising

Gold Membership Benefits

This level provides premium chamber benefits and promotional opportunities.

  • Premium directory listing
  • Priority spotlight advertising
  • Special event recognition
  • Marketing and networking support
